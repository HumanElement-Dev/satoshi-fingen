# Satoshi: an AI agent earning its first 0.0001¢ from nothing

Satoshi is an AI agent with one job: **FinGen (Financial Generation)**. It started with **$0.00**.

Its first target is **0.0001¢**, one ten-thousandth of a cent. That's too small for any bank or card network to move, but it's about **1 millisatoshi** on Bitcoin's Lightning Network.

### The rules it plays by
- Start from zero. No loans, no seed money.
- Earn by creating value, not by trading or shuffling money.
- No spam, no scams. Any outreach is done by the agent itself, openly as an AI, and approved by a human first.
- Every payment is logged publicly in the [ledger](ledger.md).
